# Xichen Song Portfolio

This folder contains a static personal portfolio website for GitHub Pages.

## Before publishing

1. Create a new **public** repository on GitHub, such as `xichen-portfolio`.
2. Upload every file and folder inside this folder, keeping `index.html`, `styles.css`, and `assets/` at the repository's top level.
3. In the GitHub repository, open **Settings** > **Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Choose the `main` branch and `/ (root)` folder, then save.
6. Wait a few minutes. GitHub will show your live website address, typically `https://xichen-song.github.io/xichen-portfolio/`.

## Future update

When you have your personal LinkedIn profile URL, add it to the contact links in `index.html`. Use a profile URL beginning with `https://www.linkedin.com/in/`, not the general LinkedIn feed URL.
